# Fediverse Actions Anyware

[English](README.md)

ログインしていない Mastodon インスタンスの投稿にも、自分のアカウントでお気に入り・ブースト・ブックマーク・返信ができる Firefox 拡張機能です。

別のインスタンスで見つけた投稿にお気に入りを付けたいとき、ふつうは URL をコピーして自分のインスタンスを開き、検索して、そこから操作する必要があります。この拡張機能は、いま見ているページのまま、それを代わりに行います。

## 使い方

1. ツールバーのアイコンからポップアップを開き、自分の Mastodon アカウント（ホームアカウント）を登録します。サインインは自分のインスタンスのページで行うので、パスワードを拡張機能が見ることはありません。
2. ログインしていない Mastodon インスタンスで投稿を開くと、返信・ブースト・お気に入り・ブックマークのボタンが、細い下線の付いたものに置き換わります。このとき、ツールバーのアイコンの星が金色になります。
3. 置き換わったボタンを押すと、ホームインスタンスでアクションが実行されます。もう一度押すと取り消せます。
4. 返信を押すと、ホームインスタンス上の同じ投稿が新しいタブで開き、そこで返信を書けます。

ボタンの下線で状態がわかります。

| 下線 | 状態 |
|------|------|
| 細い実線 | 未実行（ホームアカウントで動くボタンであることの印） |
| 流れる破線 | 実行中 |
| 太い紫の線 | お気に入り・ブースト・ブックマーク済み |
| 点線 | 失敗（理由はボタンにマウスを乗せると表示されます） |

## 対応している範囲

- 標準の Mastodon Web UI の投稿ページとタイムライン
- ホームアカウントは複数登録でき、ポップアップで選んだものが使われます
- ログインしているインスタンスのページでは何も追加しません。そのページのボタンがすでに自分のアカウントとして動くためです
- デスクトップ版の Firefox 140 以降

まだ対応していないもの:

- Misskey などの他の Fediverse ソフトウェアと、Mastodon の代替 Web UI
- Android 版 Firefox
- 設定（置き換えるボタンを選ぶ、など）

## データの扱い

拡張機能が通信するのは、登録した Mastodon インスタンスだけです。ボタンを押すと、その投稿の URL をホームインスタンスへ送って投稿を探し、アクションを実行します。開発者やほかの誰かに送ることはありません。

- 応答を速くするため、投稿の検索はボタンを押し下げた時点で始まります。押したままポインターをずらしてクリックを完了しなかった場合でも、URL は送られます
- ボタンを押していない投稿については何も送りません。投稿や閲覧中のページの内容を送ることはありません
- 登録したアカウントとアクセストークンは、Firefox 内の拡張機能のローカルストレージに保存します。ログアウトするとアクセストークンを、アカウントを削除するとそのアカウントについて保存したものをすべて削除します

## ビルド

Node.js と npm が必要です。

```sh
npm ci
node build.mjs --release
npx web-ext build --source-dir dist-release --artifacts-dir web-ext-artifacts/release --overwrite-dest
```

`dist-release/` に拡張機能が、`web-ext-artifacts/release/` に zip が出力されます。手順の詳細（英語）は [BUILD.md](BUILD.md) を参照してください。

バージョンは `0.2.0` のような git のタグから決まるため、公開用ビルド（`--release`）はタグの付いたコミットでしか作れません。タグの無いコミットでは、開発用ビルド（`node build.mjs`、出力先は `dist/`）を使ってください。この場合のバージョンは `0.0.0` になります。

`0.2.0` のようなタグを push すると、GitHub Actions が AMO（Firefox のアドオンストア）へ新しいバージョンを提出します（`.github/workflows/release.yml`）。

## 開発

開発の流れ、ディレクトリ構成、ユニットテストで確かめることと実際のブラウザで確かめることの分担は [docs/development.md](docs/development.md) にまとめてあります。

Firefox の操作には firefox-devtools MCP サーバーを使います。

```sh
claude mcp add firefox-devtools npx @mozilla/firefox-devtools-mcp@latest
```
