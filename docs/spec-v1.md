# 仕様書

## 1. 概要

### 1.1 目的

Mastodonの他インスタンスを閲覧している際に、投稿へのアクション（お気に入り、ブースト、返信等）を、自身のホームアカウントで容易に行えるよう支援するブラウザ拡張を提供する。

### 1.2 対象ブラウザ

* Google Chrome
* Mozilla Firefox

---

## 2. 用語

| 用語               | 説明                                         |
| ---------------- | ------------------------------------------ |
| ホームアカウント         | 利用者が登録したMastodonアカウント                      |
| ホームインスタンス        | ホームアカウントが所属するMastodonサーバー                   |
| アクティブアカウント       | アクションを実行する際に使用する、現在選択されているホームアカウント         |
| 対象インスタンス         | 現在閲覧しているMastodonサーバー                       |
| 対象投稿             | 現在表示している投稿                                 |

---

## 3. 機能要件

### 3.1 アカウント管理

#### 概要

利用者が使用するホームアカウントを管理できる。

#### 要件

* 複数のホームアカウントを登録できる
* 登録内容を変更できる
* 登録内容を削除できる
* アクティブアカウントを選択・切替できる

---

### 3.2 アカウント認証

#### 概要

各ホームアカウントとの認証状態を管理する。

#### 要件

* 各ホームアカウントへのログインを開始できる
* 各アカウントの認証状態を確認できる
* ログアウトできる
* アクティブアカウントが未認証の場合、アクションボタンは表示しない
* 認証エラー時は再認証フローを提供する

---

### 3.3 Mastodonページの検出

#### 概要

表示中ページがMastodonインスタンスであることを判定する。

#### 要件

* Mastodonインスタンスのページのみで機能し、それ以外のサイトでは動作しない

---

### 3.4 投稿の検出

#### 概要

画面内の投稿を識別する。

#### 要件

* 個別投稿ページに対応
* タイムライン表示に対応

---

### 3.5 アクションボタンの提供

#### 概要

対象投稿に対しアクティブアカウントで操作を行うためのボタンを提供する。

#### 対応アクション

* お気に入り
* ブースト
* ブックマーク
* 返信
* 投稿をアクティブアカウントのホームインスタンスで開く

---

### 3.6 ボタン表示方法

利用者は表示方法を選択できる。

#### 表示モード

* 元ボタンを置き換える
* 元ボタンの横へ追加する
* ポップアップメニューとして表示する

---

### 3.7 投稿のホームインスタンス表示

#### 概要

対象投稿をアクティブアカウントのホームインスタンス上で開く。

#### 要件

* ホームインスタンスに投稿が存在する場合はその投稿を表示する
* 存在しない場合は取得処理を開始する
* 取得後に表示する

---

### 3.8 エラー表示

以下の場合は利用者へ通知する。

* 未認証（アクティブアカウントが未認証）
* ホームインスタンスへ接続できない
* 投稿が取得できない
* 権限不足
* 操作失敗

---

## 4. 設定項目

| 項目          | 内容                        |
| ----------- | ------------------------- |
| アカウント管理     | ホームアカウントの登録・削除・切替         |
| ボタン表示方法     | 置換・追加・ポップアップ              |
| 有効なアクション    | 表示するボタンの選択                |
| 対象サイト       | 有効にするドメイン                 |
| テーマ         | システム設定に従う・ライト・ダーク         |

---

## 5. 非機能要件

### 5.1 操作性

* ページ読み込み後、自動的にボタンを表示する
* 利用者の追加操作を最小限にする

### 5.2 パフォーマンス

* ページ表示速度への影響を極力小さくする
* 不要な通信を行わない

### 5.3 セキュリティ

* 認証情報は利用者のみが利用できるよう管理する
* 利用者の許可なく投稿等の操作を行わない

---

## 6. 初版対象外

以下は初版では対象外とする。

* Misskey等の他Fediverseソフトウェアへの対応
* 埋め込み投稿への対応
* 管理画面機能
* 投稿作成支援
* 通知機能
* モバイルブラウザ対応
